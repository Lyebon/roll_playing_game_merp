# MERP - Role Playing Game Engine

**A command-line role-playing game engine based on the MERP (Middle-earth Role Playing) system, developed in Go.**

## Overview

MERP is an ongoing software development project focused on building an interactive, command-line role-playing game engine using Go.

The project aims to implement the mechanics and rules of the MERP tabletop RPG system, allowing users to interact with the game through a command-line interface powered by a REPL (Read-Eval-Print Loop).

The engine will handle character creation, rule resolution, dice mechanics, skill checks, and combat calculations.

Beyond its gameplay purpose, this project is intended to explore backend software development concepts, software architecture, testing strategies, and the integration of different development tools and technologies.

## Main Features

The following features represent the project's development goals:

- **Interactive REPL:** A command-line environment for interacting with the game through commands.
- **Character Creation:** Generate and configure characters using the system's rules, races, professions, and characteristics.
- **Rule Engine:** Implement the mechanics and calculations defined by the MERP system.
- **Dice System:** Handle d100 rolls and other dice mechanics required by the rules.
- **Skill Checks:** Calculate success, failure, and critical results based on dice rolls and character attributes.
- **Combat System:** Resolve combat encounters, attacks, defenses, and damage calculations.
- **Game State Management:** Manage characters and game information throughout an interactive session.
